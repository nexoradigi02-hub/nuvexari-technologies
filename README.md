# Nuvexari Technologies

A responsive React + Vite website for a digital technology studio.

**Brand line:** Innovation without limits.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. Open this folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

Vite creates the production site in `dist/`.

## Free deployment with Vercel

1. Create a GitHub repository and push this project.
2. Sign in to Vercel and import that repository.
3. Keep the detected Vite settings, or set build command to `npm run build` and output directory to `dist`.
4. Deploy and test the generated `.vercel.app` URL on desktop and mobile.

A free hosting plan and generated subdomain can be enough to start; plan terms and limits can change. A custom domain is usually a separate purchase.
